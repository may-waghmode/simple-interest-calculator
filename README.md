# Simple Interest Calculator

## Project Description
This project is a simple interest calculator that calculates the simple interest based on the principal amount, annual rate of interest, and time period. It uses a Bash script to accept user input and perform the calculation.

## Formula
Simple Interest is calculated using the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual rate of interest in percentage.
- **Time:** The time period in years.

## Features
- Accepts principal amount from the user.
- Accepts annual rate of interest.
- Accepts the time period in years.
- Calculates and displays the simple interest.
- Beginner-friendly Bash scripting project.

## How to Run
1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Give execution permission to the script:

   ```bash
   chmod +x simple-interest.sh
   ```

4. Run the script:

   ```bash
   ./simple-interest.sh
   ```

5. Enter the principal, rate of interest, and time period when prompted.

## Example
Input:
- Principal: 1000
- Rate of Interest: 5%
- Time: 2 years

Output:
- Simple Interest: 100
